動画投稿ツール

自分のYouTubeチャンネルに動画を投稿するための、個人用のコマンドラインツールです。

できること

  • 手元で作成した動画ファイルを、運営者自身のYouTubeチャンネルへアップロードする
  • タイトル・説明文・タグ・公開範囲を指定する
  • 字幕ファイル（SRT）を字幕トラックとして登録する

動画の企画から書き出しまでを自動化したうえで、最後の投稿までを一貫して行うために作られています。

使用するGoogleの権限

YouTube Data API v3 を通じて、以下の権限を利用します。

  • youtube.upload — 動画のアップロード
  • youtube.force-ssl — 字幕トラックの登録

いずれも、認証した本人のチャンネルに対してのみ使用します。他者のチャンネルやデータにはアクセスしません。

対象

一般に配布しているサービスではありません。運営者本人が自分のチャンネルを運用するために使う、ローカル実行のツールです。

取り扱う情報

認証トークンは実行している端末のローカルにのみ保存されます。外部のサーバーへ送信することはありません。 詳細はプライバシーポリシーをご覧ください。
